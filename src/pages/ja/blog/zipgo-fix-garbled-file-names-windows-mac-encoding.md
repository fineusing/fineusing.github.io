日本のビジネス環境や教育現場でMacを使っていると、一度は必ず直面する最大のストレス——それが **「Windowsから送られてきたZIPファイルを解凍すると、ファイル名が激しく文字化けする問題」** です。

取引先から受け取った「2026年度事業計画書.zip」をFinderでダブルクリックすると、エラーも出ずに一瞬で解凍されます。しかし、展開されたフォルダを開いてみると：

暗号のような記号の羅列に変わり果てており、どれがどのファイルなのか1つずつ開いて中身を確認しなければなりません。ファイル名が日本語でなくなっているため、Spotlightで検索することもできず、作業効率は著しく低下します。

なぜMacとWindowsの間でこれほど頻繁に文字化けが発生するのか、その構造的な理由と、一切の手間をかけずに解消する方法を解説します。

## 文字化けの元凶：Unicode（UTF-8）とレガシーコードページ（Shift-JIS / CP932）の衝突

このトラブルの原因は、OSがファイル名を扱う際の「文字エンコーディングの歴史的標準」の違いにあります。

1. **macOSは完全なUnicode（UTF-8）標準**：Mac OS Xの黎明期から、AppleのOS（APFSおよびHFS+）は一貫して国際標準のUTF-8を基礎としています。
2. **Windowsの標準ZIPは「Shift-JIS（CP932）」で保存される**：Windowsのエクスプローラー標準の右クリック「ZIPファイルに圧縮」機能や古い圧縮ツールは、ファイル名をUTF-8に変換せず、日本語版Windowsの標準コードページである **CP932（マイクロソフト拡張Shift-JIS）** の生バイト列のままZIPヘッダーに書き込みます。
3. **macOS標準ツールの決め打ち解釈**：macOS付属の「アーカイブユーティリティ」は、ZIPファイル内に明示的なUTF-8フラグがない場合でも、そのバイト列を無条件にUTF-8として読み取ろうとします。Shift-JISの2バイト文字コードはUTF-8のバイト配列と互換性がないため、デコードに失敗して「文字化け（Mojibake）」が発生します。

### 日本語Macユーザーを苦しめるもう一つの罠：「濁点分離問題（NFD）」
Mac側で作成したファイル名をWindowsへ送った際、「ファイル」が「ファイル」、「プレゼン」が「フレ゜セン」のように、濁点・半濁点が1文字分離してしまう現象（Unicode正規化形式 NFD / NFC の不一致）も同根のトラブルです。

## ターミナルでの対症療法とその限界

ネット上では、ターミナルで以下のように文字コードを指定して解凍する回避策が紹介されることがあります。

```bash
# Shift-JISを指定して解凍を試みるコマンド
unzip -O Shift-JIS project_assets.zip -d ./extracted
```

### なぜこの方法が実務で役に立たないのか？
1. **Mac標準の `unzip` は `-O` オプションに非対応**：macOS標準搭載のBSD版 `unzip` コマンドを実行すると、`unzip: invalid option -- O` とエラーが出て実行すらできません。利用するにはHomebrewで別のバイナリを導入する高度な環境構築が必要です。
2. **文字コードの事前判別が不可能**：送られてきたファイルが日本（Shift-JIS/CP932）なのか、中国（GBK/CP936）なのか、台湾（Big5）なのか、韓国（EUC-KR）なのかをユーザーが目視で判断してオプションを打ち分けるのは現実的ではありません。
3. **パスワード付きや分割ファイルで失敗する**：近年のAES-256暗号化ZIPや連番分割ファイルには、古いCLIツールでは太刀打ちできません。

## 決定的な解決策：ZipGoの文字コード自動判別エンジン

[ZipGo](https://apps.apple.com/app/id6799313183) は、Finderの右クリックメニューから操作するだけで、文字化けを完全に自動修復して解凍します。

ZipGoはすべてのアーカイブを機械的にUTF-8と決めつけず、ヘッダー内の生バイト列を解析して言語とコードページを高精度に自動検出します。

### 使い方：

1. 文字化けしそうなZIPファイルをFinder上で **右クリック** します。
2. **「ZipGoで解凍」**（または「同名フォルダに解凍」）を選択します。
3. ZipGoがShift-JIS（CP932）やGBKなどのエンコーディングを瞬時に見抜き、macOSに最適なUTF-8（NFC形式）へ自動変換して保存します。

```text
【従来のmacOS標準ツール】   縺ゅ＞縺_譁ｰ隕乗署譯・docx
【ZipGo による自動修復】     新規提案書_最終版.docx
```

### 解凍前に「プレビュー」で日本語を確認できる安心感
数十GBもある大容量ファイルの場合、解凍してから「やっぱり文字化けしていた……」と気づくのは時間の無駄です。
ZipGoなら、右クリックして **「プレビュー」** を選ぶだけで、アーカイブを展開することなく、正常な日本語ファイル名でツリー表示を確認できます。
