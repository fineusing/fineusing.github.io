デザイン事務所、Web制作会社、コンサルティングファーム、あるいは一般企業のビジネス現場で、Macを使ってWindowsの取引先やクライアントとデータをやり取りしていると、知らず知らずのうちに相手を困惑させていることがあります。

典型的なトラブルがこちらです：

1. Mac上で納品データフォルダを選択し、Finderで「圧縮」をクリックする。
2. 作成された `納品データ.zip` をWindows環境のクライアントへメール添付で送る。
3. 相手から解凍後に連絡が入る：**「同じ名前で先頭に `._` がついた壊れたファイルがたくさん入っていますが、ウイルスでしょうか？」「`__MACOSX` という不要なフォルダは何ですか？」**

Mac上ではすっきりと10個のファイルしか見えていなかったはずなのに、Windowsで解凍した途端、まるでゴミ箱をひっくり返したかのような20個以上の雑多なファイル群が姿を現します。

```text
【Windows側で解凍したときに見える惨状】
📁 納品データ/
├── 📁 __MACOSX/
│   ├── ._提案書_最終版.pdf
│   ├── ._キービジュアル.png
│   └── ._御見積書.xlsx
├── .DS_Store
├── 提案書_最終版.pdf
├── キービジュアル.png
└── 御見積書.xlsx
```

なぜMacは勝手にこれらのファイルを生成してしまうのか、なぜWindowsでは邪魔者扱いされるのか、そしてワンクリックで完全に綺麗なZIPを作成する方法を解説します。

---

## なぜmacOSは `__MACOSX` や `._` ファイルを作り出すのか？

この現象の背景には、Appleのファイルシステム特有の歴史的構造があります。

1. **AppleDoubleリソースフォーク**：Macのファイルシステム（APFSや旧HFS+）は、データ本体だけでなく、カラーラベル、タグ、Finderコメント、ウィンドウ表示座標、拡張属性（セキュリティ情報など）といった膨大な付加情報をファイルとセットで保持しています。
2. **標準ZIP規格との不整合**：世界標準のZIPフォーマットには、Apple独自のリソースフォークを直接格納する仕組みがありません。そこでmacOS標準の圧縮エンジンは、1つのファイルを「データ本体（例：`キービジュアル.png`）」と「付加情報（例：`._キービジュアル.png`）」の2つに分解してZIP内に書き込みます。
3. **隠しフォルダ `__MACOSX` の生成**：macOSはこの分解された `._` ファイル群を `__MACOSX` という仮想フォルダにまとめます。Mac上ではFinderが気を利かせてこれらを完全に不可視化（非表示）するため、作成者本人はその存在に気づけません。
4. **おなじみの `.DS_Store`**：Finderでフォルダを開くたび、アイコンの配置や表示順を記録するために各フォルダ内に自動生成されるmacOS専用の管理ファイルです。

### Windowsユーザーから見たストレス：
WindowsのOSはAppleDoubleの構造を知りません。エクスプローラーから見れば、`._キービジュアル.png` は単なる「1KB前後の壊れた画像ファイル」に見えます。開こうとするとエラーになり、「ファイルが破損しているのでは？」と不信感を抱かせる原因になります。

## ターミナルで除外するコマンドライン（上級者向け）とその難点

コマンドに詳しいエンジニアであれば、Finderの標準圧縮を使わず、ターミナルで以下のようなコマンドを駆使してクリーンなZIPを作成しています。

```bash
# 事前に拡張属性をクリーンアップ
dot_clean /path/to/folder

# __MACOSX や .DS_Store を除外してZIP圧縮
cd /path/to/folder
zip -r -X deliverables.zip . -x "*.DS_Store" -x "__MACOSX*" -x "*/.*"
```

`-X` オプションは拡張属性を無視し、`-x` は指定パターンの除外を指示します。

### 日常業務でこれが続かない理由：
- 毎回ターミナルを起動し、パスに日本語やスペースが含まれるディレクトリを移動（`cd`）するのは非常に面倒です。
- 1文字でもタイピングミスをすると、圧縮に失敗したり階層構造が崩れたりします。
- 営業やディレクター、総務など、コマンドラインに不慣れなチームメンバーにこの手順を徹底させるのは現実的ではありません。

---

## 最もスマートな解決策：ZipGoの「クリーン圧縮」

[ZipGo](https://apps.apple.com/app/id6799313183) を使えば、特別なコマンドを打つ必要は一切ありません。Finderの右クリックメニューから操作するだけで、macOS特有の不要ファイルを自動的に排除したクリーンなZIPを生成します。

### 操作手順：
1. Finderで圧縮したいファイルやフォルダを選択します。
2. **右クリック** して、**「ZipGoで圧縮」** を選択します。
3. ZipGoの圧縮エンジンがバックグラウンドで以下を自動実行します：
   - 全階層の `.DS_Store` ファイルを完全に除外。
   - AppleDouble `._` 補助ファイルの生成を抑止。
   - `__MACOSX` ディレクトリをアーカイブ構造から根こそぎ削除。

### Windows相手に届く結果：
Windowsの取引先がZIPを解凍すると、そこには意図したファイルとフォルダだけが整然と並びます。

```text
【ZipGo で圧縮した理想的な結果】
📁 納品データ/
├── 提案書_最終版.pdf
├── キービジュアル.png
└── 御見積書.xlsx
```

相手に無用な確認や不信感を与えず、プロフェッショナルとしての信頼感を高めることができます。
