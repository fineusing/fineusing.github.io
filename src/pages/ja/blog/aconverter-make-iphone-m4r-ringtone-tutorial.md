iPhone は直感的な操作が魅力のスマートフォンですが、**「お気に入りの音楽を着信音に設定する」**という作業に関しては、長年にわたり最も手間の多い設定の一つとして知られています。

一般的なチュートリアルでは：
1. App Store から約 1.8 GB もある「GarageBand（ガレージバンド）」をダウンロードする。
2. ファイルアプリを経由して音楽ファイルをトラックに配置する。
3. スマホの小さな画面上で2本指を使って波形を拡大・縮小しながらサビをトリミングする。
4. プロジェクトを長押しして「共有」メニューから「着信音」として書き出す。

途中で操作を誤ると最初からやり直しになり、1曲設定するだけで15分以上も時間を浪費してしまいます。

しかし、Mac 上で **AConverter** を使えば、マウス操作で波形を見ながらサビの29秒間をミリ秒単位で切り出し、滑らかなフェード処理を加えて公式規格の `.m4r` ファイルを書き出すまで、**わずか30秒で完結**します。

---

## iPhone着信音における3つの必須仕様

自作着信音を作成する前に、iOS の着信音仕様を押さえておく必要があります：
* **拡張子は必ず `.m4r` であること**：iOS の着信音は独自の AAC コンテナを採用しており、単に `.mp3` のファイル名末尾を書き換えても認識されません。
* **再生時間は29〜30秒以内であること**：iOS は30秒を超える着信音ファイルを同期時に自動的に切り捨てるか、取り込みを拒否します。
* **フェードイン・フェードアウトの設定**：サビの盛り上がり部分をいきなり再生すると、電話がかかってきた瞬間に周囲を驚かせてしまいます。出だしの滑らかな立ち上がりと、終わりの自然な減衰が不可欠です。

## Macで自作着信音を作成する3ステップ

### ステップ 1：楽曲または動画を AConverter へ追加
AConverter を起動し、お気に入りの楽曲（MP3, FLAC, M4A, WAV など）や動画クリップをウィンドウへドラッグします。

ファイル横にある「トリミング / 編集」ボタンをクリックすると、画面いっぱいに高精細な音声波形エディターが展開されます。

### ステップ 2：波形を見ながらサビをミリ秒単位で調整
波形エディター画面において：
1. **試聴しながらサビを探す**：再生ボタンをクリックし、波形上の目的のフレーズをクリックして開始位置を決めます。
2. **選択範囲を指定**：スライダーを動かすか、下部のタイムコード入力欄に直接数値を入力し、選択範囲の長さを **29.0 秒** に設定します。
3. **フェード効果を有効化（推奨設定）**：
   - **フェードイン（Fade-In）**：`0.8 秒` に設定。音が柔らかく立ち上がり、不意の爆音を防ぎます。
   - **フェードアウト（Fade-Out）**：`1.5 秒` に設定。サビの余韻を綺麗に残して自然にフェードアウトさせます。

```text
音量
  ▲       ┌──────────────────────┐
  │      /                        \   <── 1.5秒 滑らかなフェードアウト
  │     /                          \
  │    / (0.8秒 穏やかな立ち上がり)   \
  └───┴──────────────────────────────┴────► 時間
     0秒                            29秒 (iOS 最適着信音レンジ)
```

### ステップ 3：出力形式に「M4R」を選択して書き出し
フォーマットメニューから **M4R** を選択し、「書き出し」をクリックします。
Mac のハードウェアエンコーダーにより、1秒足らずでデスクトップに `.m4r` ファイルが生成されます。

## 作成した .m4r ファイルを iPhone に転送する方法（Finder経由）

サードパーティ製の転送ツールは不要です。macOS 標準の Finder だけで瞬時に同期できます：

1. **iPhone を Mac に接続**：付属のケーブルで接続し、ロックを解除して「このコンピュータを信頼」をタップします。
2. **Finder でデバイスを選択**：Finder のサイドバーにある接続中の iPhone をクリックします。
3. **ドラッグ＆ドロップで追加**：デスクトップに書き出した `.m4r` ファイルを、**Finder の iPhone 管理画面上へ直接ドラッグ＆ドロップ**します（バックグラウンドで自動的に着信音ライブラリへ格納されます）。
4. **iPhone 側で着信音を指定**：iPhone の「設定」→「サウンドと触覚」→「着信音」を開くと、リストの一番上に作成した楽曲名が表示されています。タップして選択すれば設定完了です！

家族専用の着信音や、映画のセリフ、ゲームの効果音など、AConverter を使えば思い通りの着信音を快適に作成できます。
