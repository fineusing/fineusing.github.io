macOSのFinderは美しく直感的ですが、開発現場や日々の高負荷なデスクワークにおいては、「Optionキーを押しながら慎重にクリックする」「何階層もメニューを辿る」「ウィンドウ同士を神経質にドラッグする」といった細かな操作の積み重ねが、作業のリズムを乱してしまいがちです。

絶対パスのコピー、特定ディレクトリでのターミナル起動、隠しファイルの確認、そして機密ファイルの暗号化圧縮など、エンジニアやクリエイターが1日に何度も繰り返す定番アクションを、すべてFinderの右クリックメニューに集約できたらどうでしょうか？

本記事では、Mac向けコンテキストメニュー拡張ツール [Rightly](https://apps.apple.com/app/id6806805796) を活用して、Finderを最強のコマンドセンターへと進化させる**5つの厳選テクニック**をご紹介します。

## 1. ファイルの絶対パス（POSIX パス一括コピー）をワンクリックで取得

macOSの標準機能でファイルのフルパス（POSIXパス）を取得しようとすると、キーボードの `Option`（⌥）キーを押しながら右クリックし、コンテキストメニューの中から「〜のパス名をコピー」を探して選ぶ必要があります。キーを押し忘れたり、ショートカットを度忘れした場合は、「情報を見る（⌘I）」ウィンドウを開いて場所とファイル名を手作業で繋ぎ合わせる羽目になります。

### Rightlyでの効率化テクニック
Rightlyを導入すると、右クリックメニューに**「パスをコピー」**が常に表示されます。対象のファイルやフォルダを右クリックして選ぶだけで、`/Users/username/Projects/app/config.json` といった正確な絶対パスが一瞬でクリップボードに格納されます。ターミナルや設定ファイル、チャットツールへの貼り付けがストレスフリーに行えます。

## 2. 現在開いているフォルダで「ターミナル / VS Code 瞬時起動」

エンジニアやWebディレクターが深い階層のプロジェクトフォルダでコマンドを実行したい時、ターミナルを開いてから長いパスをチマチマと入力するのは非常に非効率です：

```bash
cd ~/Documents/Clients/ActiveProject/Assets/Source
```

Tabキーで補完できるとはいえ、タイポのリスクがあり、Finderからフォルダアイコンをターミナルウィンドウにドラッグ＆ドロップする操作もウィンドウの配置によっては面倒です。

### Rightlyでの効率化テクニック
Finderの任意のフォルダの空白部分で右クリックし、**「ターミナルで開く」**または**「VS Codeで開く」**を選択するだけ。そのディレクトリを作業ディレクトリ（カレントディレクトリ）として、目的のツールが一瞬で立ち上がります。思考の勢いを止めることなく、即座にコーディングやビルドを開始できます。

## 3. ファイル名・フォルダ名だけを安全・正確にコピー

Slackなどで同僚にファイル名を伝えたい時や、プログラムのコード内にアセット名を記述したい時、ファイルを選択して `Enter` キーを押し、テキスト部分を選択して `⌘C` でコピーしていませんか？この手順は手数がかかるだけでなく、うっかりキーボードに触れてファイル名を書き換えてしまう誤操作のリスクを孕んでいます。

### Rightlyでの効率化テクニック
右クリックメニューの**「ファイル名をコピー」**を使えば、拡張子を含めたファイル名（またはフォルダ名）だけをワンクリックで安全にコピーできます。誤って名前を消してしまう心配は一切ありません。

## 4. 拡張子や隠しファイルの表示切替をその場で実行

macOSはデスクトップをすっきり見せるため、標準状態では多くのファイル拡張子を非表示にしています。しかし、開発中に `.png` と `.webp` の違いを確認したり、スクリプトの拡張子（`.sh` / `.zsh`）をチェックしたりする際、拡張子が見えないのは致命的です。また、`.env` や `.gitignore` などのドットファイル（隠しファイル）を確認するために、毎回ショートカットキー（`⌘ + Shift + .`）を思い出すのも一苦労です。

### Rightlyでの効率化テクニック
対象のファイルを右クリックして**「拡張子を表示/非表示」**を選ぶだけで、Finderの環境設定をわざわざ開くことなく、その場ですぐに切り替えられます。隠しファイルの可視化も直感的に行えるため、環境設定トラブルの調査もスムーズです。

## 5. 30種類以上の形式に対応した高圧縮＆パスワード暗号化

クライアントに成果物を納品する際や機密データをメール添付する際、macOS標準の「圧縮」機能ではシンプルなZIPファイルしか作れず、パスワードによる暗号化や、より圧縮率の高い7Z形式の選択はできません。

### Rightlyでの効率化テクニック
Rightlyは高機能なアーカイブエンジンを内蔵しており、Finderの右クリックから直接、**ZIP、7Z、TAR、GZIP** などの形式へ圧縮できます。ビジネス文書の漏洩を防ぐ強固なパスワード暗号化や、メール送信時の添付サイズ制限をクリアするための「分割圧縮」も、右クリックメニュー内で完結します。
