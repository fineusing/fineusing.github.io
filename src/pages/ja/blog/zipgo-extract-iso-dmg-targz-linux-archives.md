ソフトウェアエンジニア、インフラエンジニア、DevOps担当者、そして技術志向のMacユーザーは、Appleのエコシステム外で作成された多種多様なアーカイブやイメージファイルと日常的に向き合っています。

例えば、以下のようなタスクに直面したことはないでしょうか：

- **UbuntuやWindowsの `.iso` インストールイメージ** から、仮想ドライブとしてマウントせずに中のファイル（スクリプトや特定バイナリ）だけを取り出したい。
- オープンソースのリポジトリからダウンロードした **`.tar.gz`**、**`.tar.bz2`**、あるいは高圧縮な **`.tar.xz`** をスムーズに解凍したい。
- Debianパッケージ（**`.deb`**）やRed Hatパッケージ（**`.rpm`**）の中身を展開して、Mac上でライブラリ構成やペイロードを検証したい。
- **`.dmg` ファイル** をマウントすることなく、素早くフォルダとして展開したい（アンマウント時の「ディスクが使用中です」エラーを回避したい）。

macOS標準の **「アーカイブユーティリティ」** では、こうしたニーズに対応しきれません。標準ツールは単純な `.zip` こそ扱えるものの、`.iso` を開こうとすれば無理に仮想ディスクとしてマウントしようとし、`.tar.xz` では外側のコンテナだけを解凍して未展開の `.tar` が残るという二度手間が発生します。

今回は、仮想ドライブのマウントを一切行わず、あらゆるLinuxパッケージやディスクイメージをFinderから直接フォルダとして展開する方法を解説します。

---

## ディスクイメージの「マウント」が引き起こす3つのストレス

macOSで `.iso` や `.dmg` をダブルクリックすると、OSは標準機能（DiskImageMounter / `hdiutil`）を呼び出し、システムに仮想ボリュームとしてマウントします：

```text
/Volumes/Ubuntu 24.04 LTS amd64
```

### なぜこれが実務の妨げになるのか？
1. **デスクトップやサイドバーが散らかる**：マウントするたびにドライブアイコンがデスクトップやFinderのサイドバーに常駐します。
2. **「取り出し不可」エラーの頻発**：ターミナルのセッションやSpotlightのインデックス処理、バックグラウンドツールがボリューム内のファイルを参照していると、「ディスクが使用中であるため取り出せません」というダイアログが出てイジェクトできなくなります（最終的にターミナルで `hdiutil detach -force` を叩く羽目になります）。
3. **未対応ファイルシステムの警告**：ISO内部がmacOS非対応の特殊なフォーマット（ext4など）である場合、「セットしたディスクは、このコンピュータで読み取れないディスクでした」という不気味な警告が表示されて中身に触れなくなります。

---

## ターミナルコマンド `tar` の煩雑さ

エンジニアは通常、ターミナルでUnix標準の `tar` コマンドを使用します。

```bash
# 一般的なgzip展開
tar -xzvf archive.tar.gz

# 高圧縮なxz展開
tar -xJvf archive.tar.xz

# bzip2展開
tar -xjvf archive.tar.bz2
```

このコマンド群は強力ですが、圧縮形式ごとに異なるアルファベットのオプション（`-z`、`-j`、`-J` など）を暗記しなければなりません。さらに：
- `tar` コマンド単体では `.iso`、`.cab`、`.rpm`、`.deb` などの複合パッケージをそのまま解凍できず、`ar` や `cpio` と組み合わせる複雑なパイプ処理が必要になります。
- 予期せぬパーミッションやシンボリックリンクが含まれていると、権限エラーが発生することがあります。

## ZipGoによるスマートな直接解凍：マウント不要でフォルダ化

[ZipGo](https://apps.apple.com/app/id6799313183) を導入すると、macOSのFinderが **30種類以上の工業規格・開発用アーカイブの万能展開ハブ** へと進化します。

ディスクイメージやLinux向けパッケージを仮想ドライブとしてマウントするのではなく、「通常の圧縮アーカイブ」として直接フォルダへ展開できます。

### 対応する主要フォーマット：
- **ディスクイメージ**：`.iso`, `.img`, `.dmg`（`/Volumes/` にマウントせず直接解凍）
- **Unix / Linux 圧縮アーカイブ**：`.tar`, `.tar.gz`, `.tgz`, `.tar.bz2`, `.tbz2`, `.tar.xz`, `.txz`, `.tar.lzma`
- **Linux パッケージ**：`.deb`（Debian / Ubuntu）、`.rpm`（RedHat / Fedora / CentOS）
- **Windows インストーラ＆コンテナ**：`.cab`, `.wim`, `.vhd`, `.chm`
- **汎用・レガシー形式**：`.rar`（最新RAR5含む）、`.7z`, `.arj`, `.lzh`, `.z`

### 操作は右クリックするだけ：
1. Finderで対象のファイル（例：`ubuntu-server.iso` や `tools.tar.xz`）を右クリックします。
2. **「ZipGoで解凍」** または **「同名フォルダに解凍」** を選択します。
3. 仮想ドライブをマウントすることなく、その場でローカルフォルダへ中身が綺麗に展開されます。
   - デスクトップに余計なドライブアイコンは出ません。
   - 取り出し処理も不要です。

### プレビュー機能でピンポイント確認：
ISOの中から設定ファイル1つだけを取り出したい場合は、右クリックして **「プレビュー」** を選択します。ZipGoのプレビューアが仮想ツリーを一瞬で表示し、必要なファイルだけをドラッグ＆ドロップで抽出できます。

## 展開方法の機能比較

| フォーマット | macOS標準機能 | ターミナル（CLI） | ZipGo |
| :--- | :--- | :--- | :--- |
| **`.iso` イメージ** | 仮想ドライブとしてマウント | `hdiutil attach` | ✅ マウント不要で直接フォルダ展開 |
| **`.tar.xz` アーカイブ** | 2段階解凍（xz後にtar） | `tar -xJvf` | ✅ ワンクリックで完全解凍 |
| **`.deb` / `.rpm` パッケージ** | ❌ 開けない | ⚠️ `ar` / `cpio` が必要 | ✅ ペイロードを直接展開 |
| **`.dmg` ファイル** | 仮想ドライブとしてマウント | `hdiutil attach` | ✅ マウント不要で中身を抽出 |
| **アーカイブ内プレビュー** | ❌ 不可 | ⚠️ `tar -tf`（テキストのみ） | ✅ グラフィカルなツリー表示＋検索 |

仮想ドライブのアンマウントエラーや複雑なコマンドオプションの暗記から解放されましょう。[Mac App Store から ZipGo](https://apps.apple.com/app/id6799313183) を手に入れて、あらゆる技術フォーマットを快適に扱ってください。
