ビジネス、学術機関、官公庁などで運用されているほぼすべてのメールシステムには、送受信できる添付ファイルの容量に厳格な上限が設けられています。

- **Gmail / Google Workspace**：上限 25MB
- **Microsoft Outlook / Exchange Online**：規定で 20MB〜25MB（企業ゲートウェイの監査によりさらに厳しく制限されることも）
- **Apple Mail（iCloud メール）**：上限 20MB
- **各種プロバイダ・社内メールサーバ**：上限 10MB〜25MB

85MBのKeynoteプレゼン資料、120MBの印刷用カタログPDF、あるいは300MBのCAD図面データを至急社外へ送らなければならないとき、相手方のセキュリティポリシーによっては「外部クラウドストレージ（Google Drive、Dropbox、Box、ギガファイル便など）のURL受信・アクセスがファイアウォールで全面禁止されている」ケースが珍しくありません。

金融機関や官公庁、製造業の調達部門などでは、暗号化添付されたメールこそが唯一認められた外部通信手段であることが多いのです。

しかし、macOS標準のFinderでフォルダを圧縮しても、できあがるのは単一の「80MBのZIPファイル」だけです。それをメールに添付して送信ボタンを押した数秒後、無情にもMail Delivery Subsystemからバウンスメールが届きます：

> *"552 5.3.4 Message size exceeds fixed maximum limit."*

今回は、ターミナルを使わずに、Finderの右クリックから大容量データを25MBごとの連番アーカイブへとスマートに分割圧縮する方法をご紹介します。

---

## ターミナルの `split` コマンドで分割する危険性

macOSにはUnix標準の `split` コマンドが備わっています。コマンド操作に長けたユーザーなら、以下のように実行するかもしれません。

```bash
# フォルダをいったんZIP圧縮
zip -r presentation.zip ./Presentation_Folder

# 24MBごとに raw バイナリ分割
split -b 24m presentation.zip presentation.part_
```

### なぜこの方法がビジネスの現場で通用しないのか？
1. **正規のZIPヘッダー構造が失われる**：Unixの `split` コマンドは、単にバイナリデータを機械的に包丁でぶつ切りにするだけです。標準規格のマルチパートZIPヘッダー（`.z01`, `.z02`, `.zip`）を出力しません。
2. **送信先の相手が開けない**：相手が受け取るファイルは `presentation.part_aa` や `presentation.part_ab` といった見慣れない拡張子になります。Windows環境でこれをダブルクリックしても何も起きず、相手にターミナルやコマンドプロンプトで結合コマンドを打たせることになり、著しい迷惑をかける結果となります。
3. **暗号化の欠落**：平文のまま分割すると、メール誤送信やネットワーク経由での情報漏洩リスクに対応できません。

## ワンクリックで解決：ZipGoのインテリジェント分割圧縮

[ZipGo](https://apps.apple.com/app/id6799313183) は、PKWARE標準および7-Zip公式のマルチボリューム仕様に完全準拠した分割圧縮機能を、Finderの右クリックメニューから直接提供します。

### 手順：85MBの資料をメール向けに分割圧縮する

1. **対象を選択**：Finder上で、送信したいファイルやフォルダを選択します。
2. **右クリック** して、**「ZipGoで圧縮」** を選択します。
3. **分割サイズを指定**：
   - 設定画面の **「分割圧縮」** ドロップダウンをクリックします。
   - プリセットから **「25MB（メール添付用）」** を選択（ほかにも10MB、50MB、100MB、1GB、任意サイズの指定が可能）。
   - フォーマットは汎用性の高い `.zip`、またはより高圧縮な `.7z` を選択。
   - 機密情報が含まれる場合は **「パスワード保護（AES-256）」** にチェックを入れて暗号化キーを入力。
4. **「圧縮」をクリック**。

ZipGoが即座に連番アーカイブを生成します：

```text
Pitch_Deck_Final.z01   (24.9 MB)
Pitch_Deck_Final.z02   (24.9 MB)
Pitch_Deck_Final.z03   (24.9 MB)
Pitch_Deck_Final.zip   (10.2 MB)
```
*（すべてのファイルがGmailやOutlookの25MB制限を確実にクリアします）*

## 送信時の工夫と相手先での解凍方法

### 送信時のテクニック：
各パートが25MB以下に収まっているため：
- 4つのファイルを2通のメールに分けて送信（1通目にPart1と2、2通目にPart3と4）。
- 相手先のメールサーバがさらに厳格（1通あたり20MB制限など）な場合は、ZipGoのプリセットで「10MB」や「20MB」を指定すれば完璧に対応できます。

### 相手先（受信側）の操作：
相手に特別なITスキルは一切不要です。
1. 受信者は届いたすべての分割ファイルを **同じフォルダ** に保存します。
2. **Windowsの場合**：連番のマスターファイル（`Pitch_Deck_Final.zip` または `.7z.001`）をダブルクリックするだけ。WindowsエクスプローラーやWinRAR、7-Zipが自動的に後続パーツをメモリ上で結合して展開します。
3. **Macの場合**：`Pitch_Deck_Final.zip` を右クリックしてZipGoで解凍すれば、一瞬で元の完全なデータに復元されます。
