## なぜ従来の 5×7 固定グリッドは破綻しているのか？

Apple は長年、Launchpad のレイアウトを **「5 行 × 7 列（1 ページ最大 35 アイコン）」** という画一的な比率に固定してきました。

この iPad 由来の固定グリッドは、現代のマルチモニターや大画面ワークステーションにおいて以下のような深刻な問題を引き起こします。

1. **画面領域の莫大な無駄使い**：高精細な 4K/5K ディスプレイであれば、1 つの画面に 70〜80 本の常用アプリを美しく収める十分なピクセル数があります。それにもかかわらず、Apple の制限によって 3〜4 ページもスクロールを行き来させられます。
2. **視線移動の負荷増大**：無駄に巨大化したアイコン同士が離れすぎているため、目的のツールを見つけるために首や眼球を大きく動かさなければならず、視認性が著しく低下します。
3. **ターミナル裏技の脆弱性と破損リスク**：多くのユーザーが試してきたおなじみのコマンド：
   ```bash
   defaults write com.apple.dock springboard-columns 10
   defaults write com.apple.dock springboard-rows 8
   killall Dock
   ```
   この手法には手痛い代償が伴います。OS のマイナーアップデートや Dock の再起動で突然初期状態に戻るだけでなく、丹精込めて整理したグループフォルダが強制解体され、数百のアイコンが散乱してしまう事故が頻発していました。
