處理壓縮檔案是日常辦公與開發中不可或缺的環節。無論是下載開源程式碼包、接收客戶傳來的設計方案，還是整理封存文件，壓縮檔隨處可見。

但在 macOS 原生環境下，解壓縮的體驗往往令人困擾：
- **系統內建的「封存工具程式」功能極弱**：一旦遇到 Windows 或 Linux 使用者常用的 `.7z` 或 `.rar` 格式，直接彈窗報錯提示「無法開啟」；
- **市面上的第三方解壓縮軟體過於臃腫**：連按兩下一個檔案，彈出一個碩大的獨立軟體視窗，還要經歷廣告彈窗、選擇解壓路徑等繁瑣步驟；如果不小心點了「解壓到目前」，幾百個散亂檔案瞬間鋪滿整個桌面或「下載」資料夾，令人崩潰。

解決這個問題的優雅姿態是：**不要跳出目前資料夾，直接在 Finder 右鍵選單中搞定一切。** 這正是 [ZipGo](https://apps.apple.com/app/id6799313183) 的設計初衷。

## 常見壓縮格式的跨平台現狀

雖然 `.zip` 是最通用的格式，但在專業情境下，不同平台傾向於使用更高壓縮比的封存格式：
- **7Z (`.7z`)**：採用業界領先的 LZMA 壓縮演算法，體積比 ZIP 小得多，在開發者與遊戲資源分發中極受歡迎；
- **RAR (`.rar`)**：Windows 商業辦公與論壇下載資源的事實標準之一；
- **TAR / GZIP / BZIP2 / XZ**：Linux 伺服器打包與開源分發的標配；
- **ISO / CAB / VHD / ARJ**：光碟映像檔與系統安裝封存包。

開啟這些檔案不應該要求你安裝好幾個不同的小工具，更不需要去終端機輸入複雜難記的 `tar -xvf` 命令列。

## 右鍵原生操作的優雅之處

當你需要解壓縮某個檔案時，你的思維與注意力正停留在 **Finder 目前所處的目錄中**。你最希望的操作是「隨手一點，解壓縮完畢」。

透過深度整合於 macOS Finder 右鍵選單的 [ZipGo](https://apps.apple.com/app/id6799313183)，你能獲得以下流暢體驗：

### 1. 「解壓到目前」與「解壓到同名資料夾」自由選擇
右鍵點擊任意壓縮檔，直接呈現兩個極其清晰的選項：
- **解壓到目前資料夾**：適合壓縮檔內部本身就包含頂級父資料夾的規範封存；
- **解壓到獨立同名資料夾**：徹底杜絕「壓縮檔炸彈」！即便壓縮檔裡有數百個零散碎檔，ZipGo 也會自動為你新建一個與壓縮檔同名的資料夾並將所有檔案收納其中，保證工作目錄整潔有序。

### 2. 涵蓋超過 30 種主流與小眾格式
支援包括但不限於：`7Z`、`ZIP`、`RAR`、`TAR`、`GZIP`、`BZIP2`、`XZ`、`ISO`、`CAB`、`ARJ`、`LZIP`、`VHD` 等格式。不管是 Linux 安裝包還是十年前的舊封存檔，都能輕鬆解碼解壓縮。

### 3. 原生 Swift 打造，毫秒級多執行緒響應
ZipGo 針對蘋果 Apple Silicon（M1/M2/M3/M4）晶片架構進行了全核心多執行緒並行最佳化。解壓縮幾十 GB 的大型素材包時，效能強勁，不會阻礙系統介面回應。

## 如何在 1 分鐘內開啟右鍵解壓？

1. 前往 [Mac App Store 下載 ZipGo](https://apps.apple.com/app/id6799313183)；
2. 啟動軟體，並在「系統設定 > 延伸功能 > Finder 擴充功能」中確認已勾選 ZipGo；
3. 在 Finder 中右鍵點擊任意 `.zip`、`.rar`、`.7z` 檔案，即可直接開啟高效解壓。
