你興高采烈地將一顆裝滿重要專案檔、高畫質影音素材或備份資料的外接硬碟插上 Mac，滿心以為可以把剛整理好的文件拖進去——結果卻發現：**檔案拖不進去、無法新增資料夾，甚至點擊右鍵也沒有「刪除」或「重新命名」的選項。**

按下快速鍵 `⌘I` 開啟「取得資訊」，在最底部的權限欄赫然寫著：**「您只能讀取」**。

這是幾乎每一位 Mac 使用者都曾遭遇過的「經典痛點」。本文將深入剖析背後的根本原因，並介紹如何安全、優雅且無須格式化，徹底解決這項相容性障礙。

## 為什麼外接硬碟在 Mac 上會變成「唯讀」？

這主要是由底層磁碟檔案系統的相容性限制所致。絕大多數在 Windows 電腦上初始化、或出廠預先格式化好的外接硬碟、隨身碟與固態硬碟（SSD），預設採用的都是微軟開發的 **NTFS（New Technology File System）** 格式。

基於商業授權協議與跨系統檔案安全等考量：
- **macOS 對 NTFS 僅提供「原生讀取支援」**：也就是說你可以瀏覽裡面的檔案、播放影片，或把硬碟內的資料拷貝到 Mac 本機磁碟；
- **但 macOS 預設關閉了對 NTFS 的「寫入權限」**：導致你無法向硬碟儲存任何新檔案，無法在硬碟內直接編輯儲存文件，也無法刪除不必要的舊資料。

## 常見暫時性解決方案的重大隱患

不少使用者在遇到這個問題時，會上網搜尋應急方法，但傳統的幾種非正規手段往往暗藏高風險：

1. **終端機指令強開 Apple 實驗性寫入功能**：Apple 早期確實保留過一個實驗性的 NTFS 寫入指令，但在最新版 macOS 系統中已徹底失效或極度不穩定。強行透過終端機指令掛載極易損壞磁碟的主檔案表（MFT），導致嚴重的資料毀損。
2. **將磁碟抹除格式化為 ExFAT**：格式化意味著**硬碟內的所有現存資料將被全部清空**！若硬碟裡早已存有客戶的重要資料或數百 GB 的歷史存檔，或者這顆硬碟是同事借給你的，格式化顯然完全不可行。
3. **繁複的開源命令列工具配置**：需要進入 Mac 復原環境關閉 SIP、降低系統安全性層級，每次 macOS 系統重大升級後容易失效無法掛載。
