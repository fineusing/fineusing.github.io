## 1. 為什麼我們逐漸遠離了 QuickTime Player？

作為系統內建工具，QuickTime 確實具備原生輕量且免安裝的優點，插上傳輸線後點選「新增影片錄製」就能將手機螢幕投影上來。但在高頻率的日常使用中，它的硬傷極為明顯：

1. **完全缺乏無線連線功能**：哪怕你只是想靠在椅背上隨手查看手機上的新訊息或測試畫面，也必須翻找傳輸線插上；
2. **多裝置並行完全無法使用**：無法同時開啟兩個影片錄製視窗來並排監控兩台測試機的畫面；
3. **錄影檔案體積過度龐大**：QuickTime 預設採用極高位元率的 ProRes 或未充分壓縮的 MOV 編碼，錄製 10 分鐘就輕易吃掉好幾百 MB 甚至上 GB，完全無法直接當作官方文件、部落格或 GitHub README 的素材；
4. **缺乏原生 GIF 動態圖匯出功能**：你必須先將巨大的影片檔儲存下來，再打開第三方轉檔軟體或網站進行二次壓縮轉檔。

## 2. 傳統第三方軟體與「流氓投影 App」的常見痛點

市面上許多商業投影軟體雖然功能看似豐富，但使用體驗往往極具侵入性：

- **強制「套娃式」安裝**：必須在 iPhone 上也下載一個專屬的 App，還經常索取後台定位、相簿全量存取等敏感隱私權限；
- **畫質閹割與付費陷阱**：免費版通常只提供模糊的 720P 甚至 480P，畫面充滿毛邊雜訊；好不容易錄製完一段教學，畫面正中央卻被強制印上巨大的平台半透明浮水印；
- **後台常駐與廣告彈窗**：Mac 端安裝後，後台經常偷偷掛載各種開機自啟動的守護進程，甚至不定期跳出促銷廣告。
