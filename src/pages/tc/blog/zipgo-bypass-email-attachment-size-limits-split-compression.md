幾乎所有正規企業、金融機構、政府機關以及跨國公司的郵件伺服器，對附件大小都有著非常嚴格的硬性限制：

- **企業郵件服務（Google Workspace、Microsoft 365）**：一般附件單封信件上限通常為 20MB 到 25MB；
- **Exchange 伺服器**：預設閘道上限通常為 20MB 至 25MB；
- **Gmail**：嚴格限制 25MB；
- **蘋果 iCloud 郵件**：20MB 門檻。

很多朋友可能會說：「寄個 Google Drive、Dropbox 或 WeTransfer 連結不就可以了嗎？」

但在真實的政企、金融機構、外商或高安全等級機關對接中，對方的電腦通常處於高度受限的內部網路沙盒環境，**所有第三方公有雲端硬碟甚至外鏈下載一律被企業防火牆直接攔截封鎖**。電子郵件幾乎是唯一合規且被允許的商務檔案傳輸管道。

此時，如果你手頭有一份 90MB 的 Keynote 簡報演講稿、或者一份 150MB 的工程設計藍圖，用 Mac 內建工具壓縮出來依然是一個 80MB 的大 ZIP，一旦按下傳送，幾秒後信箱就會立刻收到冰冷的退信警告：
> *“552 5.3.4 Message size exceeds fixed maximum limit（信件容量超過伺服器限制）”*

今天我們來示範如何在 Mac 上無需輸入指令，透過右鍵選單一鍵精準切成 25MB 連號分割壓縮檔寄出。

## 為什麼不要在終端機用 Unix `split` 指令生硬拆分？

技術論壇上經常有人教你打開終端機，用 Unix 底層的 `split` 拆分檔案：

```bash
# 壓縮後使用終端機 split 切片
split -b 24m big_presentation.zip part_file_
```

### 這種生硬切法在商務場合中的致命硬傷：
1. **破壞檔案標頭資訊**：`split` 只是像菜刀切黃瓜一樣生硬地把二進位位元組流切成 `part_file_aa`、`part_file_ab`。它根本不是合規的標準分割壓縮檔案，沒有 `.z01` 或 `.7z.001` 的標準標頭結構；
2. **極大增加對方接收難度**：客戶在 Windows 上連按兩下這個 `part_file_aa` 根本打不開，難道你還要教對方法務或主管在 CMD 命令列裡輸入 `copy /b part_file_* output.zip` 嗎？這在實際職場溝通中顯得極不專業；
3. **無法加密**：明文生硬切片的碎檔若在傳遞過程中被轉寄，極易洩露核心商業機密。

## 優雅解決方案：ZipGo Finder 右鍵選單一鍵智慧分割壓縮

[ZipGo](https://apps.apple.com/app/id6799313183) 深入 macOS 右鍵選單，內建符合全球通用標準的智慧分割壓縮引擎。

它產生的是標準的 **PKWARE ZIP 規範**（`.z01`、`.z02`、`.zip`）或 **7-Zip 規範**（`.7z.001`、`.7z.002`），全球任何主流解壓縮軟體都能直接無縫辨識。

### 極簡操作示範：把一個 90MB 的檔案切片寄出

1. **選取檔案**：在 Finder 中選中你要寄送的超大檔案或資料夾；
2. **右鍵開啟壓縮**：選擇 **使用 ZipGo 壓縮**；
3. **設定分割檔案大小**：
   - 在彈出的壓縮設定面板中，找到 **分卷大小（Split Volume）**；
   - 點擊下拉預設，直接選擇 **25MB (郵件限制)**（亦可自訂輸入 10MB、50MB、100MB 或 1GB）；
   - 格式建議選擇通用的 `.zip` 或高壓縮比的 `.7z`；
   - 如含機密資料，可順手勾選 **密碼保護**（AES-256 加密）；
4. **點擊壓縮**。

ZipGo 瞬間產生一組標準連號的分割檔案：
```text
專案終稿_2026.z01   (24.8 MB)
專案終稿_2026.z02   (24.8 MB)
專案終稿_2026.z03   (24.8 MB)
專案終稿_2026.zip   (15.2 MB)
```
*(每一個檔案都嚴格控制在 25MB 安全上限以內。)*

## 寄送策略與對方解壓縮體驗

### 郵件寄送策略：
因為單封信件上限是 25MB，你可以分發 2 封郵件：
- 郵件 1 主旨：《關於XX專案資料（分割檔 1 & 2）》，附加檔案 `z01`、`z02`；
- 郵件 2 主旨：《關於XX專案資料（分割檔 3 & 4）》，附加檔案 `z03`、`zip`。

並在郵件內文中附註一句：*「請將全部 4 個附件下載存放在同一個資料夾中，連按兩下最後一個 `.zip` 檔案即可自動完整解壓。」*

### 對方解壓縮過程完全零學習成本：
對方無論使用的是 Windows 11、Windows 10 還是 Mac：
- **Windows 上**：把 4 個附件放在同一目錄，連按兩下主索引檔 `專案終稿_2026.zip`，WinRAR、7-Zip 或系統解壓縮工具會自動在背景串聯讀取 `.z01` 到 `.z03`，直接解壓出完整的 90MB 原始檔案；
- **Mac 上**：右鍵點擊 `專案終稿_2026.zip` 使用 ZipGo，一鍵解壓縮還原。
