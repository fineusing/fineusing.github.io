你可能經歷過這種令人百思不得其解的怪現象：

手頭上的 NTFS 外接硬碟昨天在 Mac 上還能順暢寫入，今天借給使用 Windows 電腦的同事拷貝檔案，再拿回 Mac 上接好，**它居然又變成唯讀了！**

甚至無論你怎麼重新插拔、重新開機，檔案依舊只能瀏覽、無法修改或存入新檔案。打開終端機查看系統主控台日誌，通常會看到類似的一行報錯訊息：

```bash
Volume is dirty. Run chkdsk on Windows to fix.
Refusing to mount read-write: Windows is hibernated or uncleanly unmounted.
```

明明檔案都完整無損、硬碟在 Windows 上也能正常開啟，為什麼拿到 Mac 上就被無情打上「唯讀鎖定」的標籤？在身邊沒有 Windows 電腦的情況下，如何在 Mac 上直接救活它？

---

## 罪魁禍首：Windows 的「不正常關機標記（Dirty Bit）」與快速啟動

這個問題的根本原因，並非你的 Mac 故障，而是**微軟 Windows 系統的預設機制給外接硬碟埋下的隱患**。

具體體現在兩個最常見的日常行為：

### 1. 拔線前沒有點擊「安全地移除硬體並退出媒體」
絕大多數 Windows 使用者習慣在拷貝完檔案後直接拔除傳輸線。然而，Windows 在背景對外接磁碟預設開啟了「寫入快取」。直接拔線會導致檔案系統日誌（$LogFile）未能完成最終檢查點的確認，NTFS 宗卷標頭會被系統強制寫入一個 **「Dirty Bit（不正常關機髒標記，即 0x0001 標記位元）」**。

### 2. Windows 預設啟用的「快速啟動（Fast Startup）」
從 Windows 10 起，微軟為了大幅縮短開機時間，預設啟用了「快速啟動」功能。  
當你在 Windows 電腦上點選「關機」時，系統實際上**並沒有真正徹底卸載外接儲存裝置**，而是將當前的核心狀態與掛載設定寫入休眠檔案，外接硬碟實質上處於「半鎖定」的假死狀態。

### 為什麼 Mac 會強制拒絕寫入？
當帶有「Dirty Bit 標記」或處於休眠鎖定狀態的硬碟接上 Mac 時，任何遵循資安規範的檔案系統驅動程式都會面臨嚴峻考驗：  
若此時強行向該分割區寫入新檔案，**極大機率會與 Windows 尚未寫入實體磁碟的快取資料發生位址衝突，直接導致現有檔案被覆寫破壞**！  
因此，macOS 的防護機制會強制將其掛載為保護性唯讀模式。

---

## 過去唯一的解法：四處借 PC 執行 chkdsk

在過去遭遇這種情況時，Mac 使用者往往無計可施，唯一的解決路徑極其繁瑣：

1. 到處找同事或朋友借一台 Windows 電腦；
2. 把硬碟插上去，打開 Windows 終端機（CMD / PowerShell），輸入指令：  
   `chkdsk /f E:`（假設磁碟機代號為 E）；
3. 等待 Windows 掃描並修復游離的索引節點，清除 Dirty Bit；
4. 最後點選右下角「安全移除硬體」，才能拿回 Mac 恢復讀寫權限。

若你人在外出差、或整個工作室清一色都是 Mac，這個小小的「Dirty Bit」足以讓整個工作進度徹底癱瘓。

## 現代化解法：在 Mac 上使用 NTFSSync 直接急救與清除

針對這個高頻發生的痛點，[NTFSSync](https://apps.apple.com/app/id6475194342) 在純使用者態的 FUSE-T 架構中深度整合了專業的 **NTFS 磁碟急救與修復引擎**。

你完全無須尋找 Windows 電腦，直接在 Mac 上就能三步驟完成磁碟修復：

### 第一步：連接並辨識異常宗卷
將唯讀的 NTFS 外接硬碟連接至 Mac，啟動 **NTFSSync**。軟體主介面會立即偵測到該外接儲存設備，並在狀態欄清晰標示出檔案系統異常或唯讀鎖定狀態。

### 第二步：執行一鍵磁碟急救與修復
1. 選取該外接磁碟，在功能面板中點擊 **「磁碟急救 / 修復（First Aid）」**；
2. NTFSSync 會在使用者空間啟動深層檢查元件，逐一掃描該硬碟的主檔案表（MFT）、校驗交易日誌一致性，並清理游離的未關閉交易；
3. 隨後，軟體會安全清除留存在宗卷標頭中的「Dirty Bit」標記與休眠鎖定旗標。

### 第三步：自動重新掛載為完全讀寫
修復過程通常僅需 **5 到 15 秒**。修復完成後，NTFSSync 會自動將該磁碟以讀寫模式重新掛載至 Finder 中。

此時你可以再次按下快速鍵 `⌘I` 檢查磁碟資訊，原本的「您只能讀取」已順利轉為「您擁有讀取與寫入權限」，所有檔案完好無損，即刻恢復自由存取與編輯。

## 避免外接硬碟再次觸發唯讀鎖定的 2 個好習慣

為了避免日後頻繁觸發系統防護機制，建議建立良好的使用習慣：

- **在 Windows 上徹底關閉「快速啟動」**：若該台 PC 是你自己的電腦，可在 Windows「控制台 - 電源選項 - 選擇按下電源按鈕時的行為」中，取消勾選「開啟快速啟動」；
- **在 Mac 上拔除傳輸線前務必先退出**：在拔下 USB 連接線之前，請在 Finder 側邊欄點擊退出圖示，或使用 NTFSSync 選單列中的「一鍵安全退出所有磁碟」。等待硬碟圖示完全自螢幕消失後，再拔除傳輸線。
