每隔幾年做一次數位資產大整理，總會遇到幾個彷彿來自「數位史前時代」的神祕音訊格式：

- **Windows 時代的遺產：`.wma`**：當年 Windows XP / Win7 時代使用 Windows Media Player 擷取 CD 音軌存下來的幾百首經典老歌，拷貝到現在的 Mac 電腦上，按兩下直接彈出視窗：「QuickTime Player 無法打開此檔案」；
- **通訊軟體匯出的語音備份：`.amr`**：透過手機助手把幾年前與家人極其珍貴的語音留言、舊款 Android 手機的通話錄音匯出來，格式全是 AMR，不僅現代播放器無法識別，傳給別人也根本打不開；
- **Apple 自家的冷門封裝：`.caf`**：部分專業錄音 App 或 iOS 內部生成的 Core Audio Format 容器，在非 Apple 裝置或剪輯軟體裡頻繁回報不相容錯誤。

這些音訊裡面往往封存著極具紀念價值的家庭回憶、重要商業取證錄音或是絕版音軌，絕不能因為播放器無法讀取就任由它們變成數位垃圾。

透過 **AConverter** 的通用多格式引擎，可以在 Mac 本機一網打盡這些冷門老舊格式，將它們一鍵「格式救援重構」為全球通用的高音質 MP3 或 M4A。

## 3 步救回老舊音訊實作流程

### 第一步：全選拖入，無需區分副檔名
不管待整理的資料夾裡混雜了多少種冷門格式：`amr`、`wma`、`caf`、`mp2`、`ac3`……直接把它們全部選取，拖入 AConverter 的轉換清單中。

AConverter 內建的深度中繼資料探測引擎會自動穿透副檔名，準確識別出實際的音訊編碼與聲道結構。

### 第二步：選擇目標規格（推薦參數）
根據音訊原始品質選擇最合適的輸出配置：
* **如果是語音備忘錄或通話錄音（AMR 格式）**：
  - AMR 本身屬於低位元率語音編碼（通常只有 12.2 kbps），強行轉成 320kbps 也無法提升音質，反而浪費空間；
  - **推薦設定**：格式選擇 **MP3**，位元率選擇 **64 kbps 或 128 kbps**，取樣率設定為 **44,100 Hz**。既能完整還原原聲的每一絲細節，單條 1 分鐘語音體積還不到 1MB，非常便於通訊軟體轉發與雲端硬碟長期封存；
* **如果是經典老歌與 CD 擷取（WMA 格式）**：
  - **推薦設定**：格式選擇 **MP3**，位元率拉到最高 **320 kbps**，確保原音訊的動態音場不發生二次損耗。

### 第三步：一鍵批次轉碼
在右上角選擇並行執行緒數，點擊「開始轉換」。

實測將包含 120 個老舊 AMR 錄音片段與 80 首 WMA 歌曲的資料夾進行批次轉換，**總耗時僅 12 秒**，全部檔案均被順暢轉換為標準的 MP3。
