## 蘋果原生啟動台的「佈局黑盒子」與容易重設的宿疾

許多人以為啟動台的佈局只是一份簡單的文字設定檔，其實不然。

在 macOS 底層，蘋果將啟動台的所有圖示座標、資料夾階層關係與排序，存放在一個隱藏路徑下的 SQLite 資料庫中：
`~/Library/Application Support/Dock/<UUID>.db`

這個資料庫存在幾項極為脆弱的致命硬傷：

1. **完全無內建備份機制**：蘋果從未在「系統設定」或 Finder 中提供「匯出啟動台佈局」的選項；
2. **極易觸發重設**：當系統安裝了某款包含特殊字元的軟體，或透過「系統移轉輔助程式」從舊機匯入時，只要 SQLite 資料庫中的某個索引出現細微不一致，macOS 的防護機制便會直接執行強制重設——**清空自訂資料庫，重新按字母排序生成預設介面**；
3. **多台設備無法自動同步**：若你同時擁有公司配發的 MacBook Pro 與家中的 Mac mini，你必須在兩台機器上手動排兩次一模一樣的資料夾，費時又費力。
