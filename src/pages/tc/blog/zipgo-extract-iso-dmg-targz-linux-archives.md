工程師、維運工程師、科研人員以及經常折騰軟體的 Mac 深度使用者，日常幾乎不可避免地要接觸各種非標準 ZIP 的專業封裝檔案：

- 從開源映像網站下載的 **Ubuntu / Windows `.iso` 作業系統映像檔**，只想提取裡面的某一個驅動程式或開機腳本；
- 開源專案打包的 **`.tar.gz`**、**`.tar.bz2`** 或高壓縮比的 **`.tar.xz`** 原始碼套件；
- Linux 伺服器上分發用的 Debian 安裝套件（**`.deb`**）或 Red Hat 安裝套件（**`.rpm`**）；
- 蘋果自家的 **`.dmg`** 映像檔案，只想安靜解開裡面的 App 資源而不想走繁瑣的磁碟掛載流程。

如果只用 macOS 內建的「封存工具程式」，你會發現處處碰壁：遇到 `.iso` 或 `.dmg`，系統會不由分說強行呼叫磁碟掛載程式將其作為虛擬磁碟掛上桌面；遇到 `.tar.xz`，連按兩下一次只解出外層的 `.tar`，你還得再手動連按兩下第二次才能解出最終目錄。

今天我們就來聊聊這些專業封裝格式在 Mac 上的解壓痛點，以及如何像處理普通壓縮檔一樣在 Finder 裡一鍵解壓縮。

---

## 為什麼「磁碟映像檔掛載」在日常處理中非常惱人？

連按兩下一個 `.iso` 或 `.dmg` 時，macOS 預設行為是呼叫系統核心的 `hdiutil` 把它掛載成一個虛擬驅動器卷宗（Volume）：

```text
/Volumes/Ubuntu 24.04 LTS amd64
```

### 這種機制帶來的幾個高頻痛點：
1. **桌面與 Finder 側邊欄圖示氾濫**：每掛載一個 ISO，桌面就會多出一個白色光碟圖示；
2. **「磁碟正在使用中」無法退出的尷尬**：如果你在終端機裡 `cd` 進入了該目錄，或者某個背景索引工具正在掃描它，點擊右鍵「退出」就會無休止彈窗提示「因為一個或多個程式正在使用該磁碟，所以無法退出」，最後逼得你只能去終端機輸入 `hdiutil detach -force` 強制卸載；
3. **唯讀保護與權限限制**：掛載出來的虛擬磁碟是嚴格唯讀的，你無法在裡面直接拖曳重整檔案，必須全部複製到本機硬碟才能操作；
4. **格式不相容直接報錯**：若該 ISO 內部採用的是 Linux 原生的 ext4 等非蘋果原生檔案系統，macOS 會直接跳出刺眼的警告：「此電腦無法讀取您插入的磁碟」。

## 終端機 `tar` 指令的記憶負擔

在終端機命令列中，資深工程師習慣輸入 `tar` 指令：

```bash
# 解壓標準 gzip 打包檔案
tar -xzvf package.tar.gz

# 解壓現代高壓縮率的 xz 打包檔案
tar -xJvf package.tar.xz

# 解壓 bzip2 打包檔案
tar -xjvf package.tar.bz2
```

雖然這套指令很強大，但 `-z`、`-j`、`-J` 等參數英文字母極其容易記混。而且對於 `.iso`、`.cab`、`.rpm`、`.deb` 這種異構格式，`tar` 指令根本無能為力，你還得去安裝 `ar`、`cpio` 或 `7z` 命令列工具來進行管道串接。

## 優雅降維：使用 ZipGo 右鍵直解 30+ 格式

[ZipGo](https://apps.apple.com/app/id6799313183) 讓 macOS Finder 真正具備了全格式直接解壓能力。

它不再把磁碟映像檔與專業安裝套件當作「外部磁碟」，而是將其作為普通的**資料容器**處理，支援多達 **30 餘種主流與專業格式**：

### 核心支援格式一覽：
- **光碟與系統映像檔**：`.iso`、`.img`、`.dmg`（無需掛載，直接解壓出所有目錄檔案）；
- **Unix & Linux 封存**：`.tar`、`.tar.gz`、`.tgz`、`.tar.bz2`、`.tbz2`、`.tar.xz`、`.txz`、`.tar.lzma`（一步到位，絕不重複連按兩次）；
- **Linux 軟體套件**：`.deb`（Debian / Ubuntu）、`.rpm`（CentOS / Fedora / RHEL）；
- **Windows 安裝檔與虛擬磁碟**：`.cab`、`.wim`、`.vhd`；
- **經典高壓縮比格式**：`.7z`、`.rar`（含 RAR5 全系列）、`.arj`、`.lzh` 等。

### 如何操作？
1. 在 Finder 中選中任何 `.iso`、`.tar.xz` 或 `.dmg`；
2. 點擊滑鼠右鍵，選擇 **使用 ZipGo 解壓**（或 **解壓到目前目錄** / **解壓到同名資料夾**）；
3. ZipGo 瞬間完成內部資料解包，輸出乾乾淨淨的本機資料夾。
   - 桌面不會冒出任何暫存光碟圖示；
   - 側邊欄沒有任何驅動器佔用；
   - 用完直接刪除資料夾，絕不觸發「磁碟忙碌無法退出」的惱人彈窗。

### 免解包，右鍵秒級預覽內部結構
如果手頭有一個 8GB 的 Ubuntu 映像檔，你只想確認裡面是否有包含某一個 `.conf` 範本：
- 右鍵點擊該 ISO，選擇 **預覽壓縮包**；
- ZipGo 會在毫秒級展開該映像檔內部的檔案系統樹狀結構，支援階層穿透與即時搜尋，甚至支援**單獨把那一個設定檔拖曳出來**，省時又節省寶貴的硬碟空間。
