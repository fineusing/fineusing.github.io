## 純文字搜尋框的三大現實軟肋

像 Spotlight 或 Raycast 這樣的鍵盤啟動器，確實是效率愛好者的利器。但只要遇到以下三種日常場景，純文字輸入就會立刻卡關：

1. **「話到嘴邊想不起名字」的拼寫遺忘**：上週安裝了一個用來去除圖片背景的開源小工具，或是一個測試 API 的輔助客戶端，你只記得它的圖示是紫色的，名字既不是 Background 也不是 Remove。你在 Spotlight 裡輸入幾個關鍵字毫無結果，最後只能挫敗地打開 Finder 慢慢找；
2. **輸入法狀態切換的打斷**：很多中文使用者在打字時輸入法處於中文狀態。按下 `⌘ 空格` 喚出搜尋框，輸入 `ps` 卻變成了注音或候選字，必須手動按 CapsLock 或 Shift 切回英文再重敲一次，原本宣稱毫秒級的操作被硬生生打斷；
3. **缺乏「全覽與挑選（Browsing）」的視角**：有時候你並不是要找某一個具體軟體，而是想看看「我電腦裡目前裝了哪些影片轉檔工具？」或者「畫心智圖的軟體有哪幾套？」。純文字框給不了你這種俯瞰挑選的全局視野。
