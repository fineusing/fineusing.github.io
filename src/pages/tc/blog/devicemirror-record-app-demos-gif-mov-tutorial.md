身為產品經理、技術部落客或獨立開發者，一定對下面這套讓人崩潰的「繁瑣流程」深惡痛絕：

1. 手機拉下控制中心，按下「螢幕錄製」按鈕，等待倒數 3 秒；
2. 開始操作 App 進行功能示範，緊張操作完畢後，點擊頂部紅色膠囊停下錄影；
3. 手機相簿裡多出了一段數百 MB 的 `.mp4` 影片，透過 AirDrop 傳送到 Mac，中途偶爾還會搜尋不到設備而中斷；
4. 傳到電腦後，打開昂貴的專業剪輯軟體或線上轉檔網站，手動把前後多餘的畫面剪裁掉；
5. 最後再使用轉檔工具壓製成 GIF，結果不僅檔案肥大到 30MB 導致無法上傳，畫質還嚴重失真變色、掉影格嚴重。

為了一個短短 5 秒鐘的點擊動畫，常常白白耗費一二十分鐘。

其實更聰明、更優雅的做法是：**直接在 Mac 電腦端完成投影、按需精準錄製與即時壓制**。有了 **DeviceMirror**，你完全不需要在手機相簿裡殘留一堆多餘的暫存錄影檔案。

## 為什麼直接在 Mac 端錄製具備壓倒性優勢？

### 1. 手機儲存空間零負擔
新一代 iPhone 的高解析度相機與高更新率螢幕，使得手機原生螢幕錄影的檔案體積極為龐大，隨便錄製兩分鐘教學就可能吃掉好幾 GB 容量。直接在 Mac 上投影錄影，畫面資料透過記憶體通道即時編碼，產生的檔案直接儲存於 Mac 的本機 SSD 上，完全不消耗手機寶貴的儲存空間。

### 2. 格式一步到位：原生支援 GIF 與 MOV
DeviceMirror 直接內建了針對圖文教學常見的編碼輸出預設集：
- **GIF 動態圖**：專為 GitHub README、Notion / 知識庫、部落格排版進行深度最佳化。內建動態調色盤取樣演算法，有效避免傳統轉換工具常見的彩色噪點與漸層斷層，將檔案大小精準控制在常見平台的上傳上限以內。
- **MOV / MP4 影片**：適合製作高畫質線上教學、YouTube 互動拆解短片，支援完整影格率輸出，色彩精準還原無失真。

### 3. 原生音訊與操作音效純淨擷取
手機內建錄影若開啟麥克風，容易收進周遭鍵盤聲與環境雜音；若關閉麥克風，有時又無法單獨錄製 App 內部的音效反饋或語音播報。DeviceMirror 走系統底層音訊通道，原汁原味同步擷取軟體內部音效，背景完全無雜音干擾。

## 5 分鐘上手：極速產出高品質互動示範 GIF

```text
[iPhone 操作示範] ──(AirPlay / USB 投影)──> [DeviceMirror 視窗]
                                                   │
                                                   ├──> 點擊「開始錄影」
                                                   │     └── 選擇格式：GIF / MOV / MP4
                                                   │
                                                   └──> 示範完畢停止，Mac 桌面立即生成現成素材！
```

### 第一步：建立鏡像連線
- 若追求極致便捷，手機與電腦處於同個 Wi-Fi 環境時，iPhone 下拉控制中心點選「螢幕鏡像輸出」，選擇 DeviceMirror 即可。
- 若追求極致高解析度與零延遲，插上 USB-C 傳輸線，秒級進入硬體直連模式。

### 第二步：挑選目標編碼格式
在 DeviceMirror 視窗控制列中，點選「錄影設定」圖示：
- **網頁或說明文件嵌入**：勾選 **GIF**，可自由調整影格率（推薦 15~30 FPS，兼顧流暢度與輕量體積）；
- **剪輯素材或存檔**：勾選 **MOV** 或 **MP4**。

### 第三步：隨點隨錄與即時產出
在開始示範操作前，點擊紅色的**「開始錄製」**。
在手機上從容操作：點選按鈕、展開抽屜選單、滑動卡片清單。操作完畢後，隨手在 Mac 上按一下停止按鈕。

**Mac 桌面上會立刻出現剛才錄製完成的檔案**。直接將生成的 `.gif` 拖曳進 Notion、Markdown 編輯器或簡報中，全程不到 30 秒，流程極致順暢。

## 靜態圖文教學需求：一鍵高解析度截圖

除了動態影片，撰寫功能教學通常也少不了清晰的步驟截圖。

過去在 iPhone 上截圖，常因「電源鍵 + 音量鍵」施力不均而誤觸螢幕鎖定。
而在 DeviceMirror 視窗中，只需點擊內建的**「截圖」**按鈕（或使用對應快速鍵）：
- 支援輸出 **PNG**（完整保留無損半透明與抗鋸齒邊緣，適合介面細部拆解）；
- 支援輸出 **JPEG**（檔案輕量且體積小，適合各類網路論壇發布）。

將工作流程從「手機錄製 + 傳輸 + 轉檔」全面升級為「Mac 電腦端直出」，節省下來的不只是硬碟空間，更是專注於內容創作的寶貴心流。
