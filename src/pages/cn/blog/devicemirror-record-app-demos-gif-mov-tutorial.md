做产品经理、技术博主或者独立开发者的人，一定对下面这套“折磨流”操作深恶痛绝：

1. 手机打开控制中心，按下“屏幕录制”，倒数 3 秒；
2. 操作 App 录制演示，手忙脚乱操作完，点顶部红条停止录屏；
3. 相册里多出来一个几百兆的 `.mp4` 文件，通过 AirDrop 传给 Mac，中途偶尔搜索不到设备断联；
4. 传到电脑后，打开昂贵的第三方视频剪辑软件或者在线网站，把前后无效的多余画面裁剪掉；
5. 最后再用格式转换器压制成 GIF，往往不仅体积膨胀到 30MB 传不上去，而且画质严重发灰掉帧。

为了录制一个 5 秒钟的点击动画，常常浪费一二十分钟。

其实更聪明的做法是：**直接在 Mac 电脑端完成投屏、按需录制与即时压制**。用 **DeviceMirror**，你完全不需要在手机相册里留下一堆垃圾视频碎屑。

## 为什么直接在 Mac 端录制优势明显？

### 1. 存储零负担
现在的 iPhone 相机传感器和高刷屏幕导致原生录屏体积极为恐怖，随意录上两分钟教程就可能占用好几个 G。直接在 Mac 上投屏录制，数据流通过内存管道实时编码，生成的文件直接落盘在 Mac 的 SSD 上，完全不消耗手机储存。

### 2. 格式一步到位：原生支持 GIF 与 MOV
DeviceMirror 直接内置了针对教学图文的常用编码预设：
- **GIF 动图**：专为 GitHub README、语雀/飞书知识库、微信公众号排版调优。内置调色板动态采样算法，有效避免传统转换工具常见的彩色噪点和色阶断层，文件体积精准控制在平台上传限制以内。
- **MOV / MP4 视频**：适合制作高清视频课程、B站/YouTube 交互拆解视频，支持全帧率导出，色彩精准无损。

### 3. 系统音频与操作声精确捕获
手机自带录屏如果打开麦克风，容易录进环境杂音；如果关闭麦克风，有时又无法单独捕获 App 内原生的按键音效或语音播报。DeviceMirror 走系统级底层音频管线，原汁原味录制软件内音效，背景纯净无噪。

## 5 分钟上手：极速输出一个精美交互 GIF

```text
[iPhone 演示界面] ──(AirPlay / USB 投屏)──> [DeviceMirror 窗口]
                                                    │
                                                    ├──> 按下「录制」按钮
                                                    │     └── 选择格式：GIF / MOV / MP4
                                                    │
                                                    └──> 演示结束，桌面立即生成可用素材！
```

### 第一步：开启镜像连接
- 如果追求极致便携，手机与电脑处于同个 Wi-Fi 时，iPhone 下拉控制中心点击“屏幕镜像”，选择 DeviceMirror 即可。
- 如果追求 4K 超高清晰度，插上 USB-C 数据线，秒级进入有线直连模式。

### 第二步：选择目标编码格式
在 DeviceMirror 窗口顶部工具栏，点击“录制设置”图标：
- **做网页或文档嵌入**：勾选 **GIF**。你可以自由选择帧率（推荐 15~30 FPS，平衡体积与流畅度）；
- **做剪辑素材或视频归档**：勾选 **MOV** 或 **MP4**。

### 第三步：即点即录与精准裁剪
在开始演示前，点击红色的**“开始录制”**。
手指在手机上从容操作：点击按钮、展开抽屉菜单、滑动列表。操作完毕后，随手再点一下停止。

**桌面会自动出现刚才录制完成的文件**。你直接将生成的 `.gif` 拖进飞书文档、Notion 或者 Markdown 编辑器中，前后耗时不到 30 秒，过程丝滑连贯。

将工具链从“手机录制+传输+转码”升级为“电脑端直出”，节省下来的不仅是磁盘空间，更是宝贵的创作心流。
