## 为什么音乐软件要把音乐锁进 .ncm 和 .mflac / .mgg？

很多朋友误以为只要自己是“黑胶 VIP”或者“绿钻豪华会员”，下载下来的就是属于自己的音频文件。事实并非如此：

```text
[用户付费下载] 
      │
      ▼
[专属封装加密]
 ├─ 网易云音乐: .ncm (AES 密钥封装的混淆容器)
 ├─ QQ 音乐标准品质: .mgg (加密 Ogg 封装)
 └─ QQ 音乐无损品质: .mflac (混淆头部与密钥流的 FLAC 容器)
      │
      ▼
[非官方播放器] ──(无法读取私有格式)──► [车载/DAP 报错跳过]
```

这些专属格式存在两大硬伤：
1. **设备排他性**：普通的汽车中控车机、便携式无损播放器（DAP）、家用 CD/流媒体数播解码器根本没有这些软件的私有解密证书，直接当作坏损文件处理；
2. **时效性封锁**：只要会员一到期，或者客户端版本一更新，原本离线在本地的歌曲甚至会在客户端里“变灰”无法播放。

## 传统解决方法的 2 大避坑点

在找到 AConverter 之前，我测试过市面上常见的两类替代方案，但都有明显的硬伤：

### 1. 网页端在线转换工具（隐私黑洞与尺寸限额）
很多所谓的“在线音频转换”网页，要求用户把整首歌上传到他们的远程服务器。
* **速度龟速**：一首无损歌曲 30MB~50MB，上传需要十几秒，转码排队一分钟，下载又要十几秒；
* **文件尺寸限制**：未付费用户限制单个文件 50MB 以内，长音频或整张母带大包直接报错；
* **隐私与版权风险**：你的个人音频被长期缓存在第三方未知服务器上，风险极大。

### 2. GitHub 开源命令行脚本（环境门槛高）
虽然开源社区有部分 Python / Node 脚本，但对 macOS 普通用户极不友好：需要手动安装 Homebrew、配置 Python 环境、安装 ffmpeg 依赖，稍微遇到一个权限错误就卡住不动。
