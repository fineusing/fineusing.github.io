每隔几年做一次数字资产大整理，总会遇到几个仿佛来自“数字史前时代”的神秘音频格式：

- **Windows 时代的遗孤：`.wma`**：当年在 Windows XP / Win7 时代用 Windows Media Player 抓轨 CD 存下来的几百首经典老歌，拷到现在的 Mac 电脑上，双击直接弹窗：“QuickTime Player 无法打开此文件”；
- **微信导出的语音备份：`.amr`**：通过手机助手把几年前与家人极其珍贵的微信语音、老式安卓手机的通话录音导出来，格式全是 AMR，不仅现代播放器无法识别，发给别人也根本打不开；
- **苹果自家的生僻封包：`.caf`**：部分专业录音 App 或 iOS 内部生成的 Core Audio Format 容器，在非苹果设备或剪辑软件里频繁报错不兼容。

这些音频里面往往封存着极具纪念价值的家庭回忆、重要商业纠纷取证录音或是绝版音轨，绝不能因为播放器不认就任由它们变成数字垃圾。

通过 **AConverter** 的通用多格式引擎，可以在 Mac 本地一网打尽这些冷门老旧格式，将它们一键“洗白”为全球通用的高音质 MP3 或 M4A。

 ├── .amr ── 2G 时代手机语音压缩标准，单声道窄带编码，现代主流播放器大多不作适配
 └── .caf ── 苹果 Core Audio 早期专有容器，Windows 与 Android 体系几乎完全不认
      │

现代操作系统为了轻量化与安全性，在持续精简底层的陈旧编解码库。对于普通用户来说，为了听两首老歌专门去装一个满屏流氓插件的万能播放器，体验极其糟糕。

最健康的长久保存方式，就是趁着现在把这些冷门格式统一批量转码为**开放、标准、未来 50 年都不会淘汰的通用容器（如 MP3、M4A 或 FLAC）**。

## 3 步救回老旧音频实操流程

### 第一步：全选拖入，无需区分扩展名
不管待整理的文件夹里混杂了多少种冷门格式：`amr`、`wma`、`caf`、`mp2`、`ac3`……直接把它们全部框选，拖入 AConverter 的转换列表。

AConverter 内置的深度元数据探测引擎会自动穿透文件扩展名，准确识别出实际的音频编码与声道结构。

### 第二步：选择目标规格（推荐参数）
根据音频原始质量选择最合适的输出配置：
* **如果是微信语音或通话录音（AMR 格式）**：
  - AMR 本身属于低码率语音编码（通常只有 12.2 kbps），强行转成 320kbps 也无法提升音质，反而浪费体积；
  - **推荐设置**：格式选择 **MP3**，比特率选择 **64 kbps 或 128 kbps**，采样率设置为 **44,100 Hz**。既能完整还原原声的每一丝细节，单条 1 分钟语音体积还不到 1MB，非常便于微信转发与云盘长期存档；
* **如果是经典老歌与 CD 抓轨（WMA 格式）**：
  - **推荐设置**：格式选择 **MP3**，比特率拉到最高 **320 kbps**，保证原音频的动态声场不发生二次损耗。

### 第三步：一键批量转码
在右上角选择并发线程数，点击「开始转换」。

实测将包含 120 个老旧 AMR 录音片段与 80 首 WMA 歌曲的文件夹进行批量转换，**总耗时仅 12 秒**，全部文件均被顺畅转换为标准的 MP3。

## 真实体验：给老旧录音加上 0.5 秒淡入淡出

在整理这些早期录音时，我发现很多 AMR 微信语音开头和结尾常常带有一声刺耳的“咔哒”底噪。

AConverter 的贴心之处在于，即使在批量转码时，你也可以在输出设置里勾选一个极小的**「淡入 0.2 秒 / 淡出 0.3 秒」**平滑处理。这样转换出来的 MP3 在播放时，开头与结尾都会极其柔和自然，彻底消除了老旧设备硬件开关麦克风带来的爆音干扰。
