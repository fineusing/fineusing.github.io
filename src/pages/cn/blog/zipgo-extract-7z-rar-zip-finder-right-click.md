处理压缩文件是日常办公与开发中不可或缺的环节。无论是下载开源代码包、接收客户传来的设计方案，还是整理归档文档，压缩包随处可见。

但在 macOS 原生环境下，解压缩的体验往往令人捉急：
- **系统自带的“归档实用工具”功能极弱**：一旦遇到 Windows 或 Linux 用户常用的 `.7z` 或 `.rar` 格式，直接弹窗报错提示“无法打开”；
- **市面上的第三方解压软件过于臃肿**：双击一个文件，弹出一个硕大的独立软件窗口，还要经历广告弹窗、选择解压路径等繁琐步骤；如果不小心点了“解压到当前”，几百个散乱文件瞬间铺满整个桌面或“下载”文件夹，极其崩溃。

解决这个问题的优雅姿态是：**不要跳出当前文件夹，直接在 Finder 右键菜单中搞定一切。** 这正是 [ZipGo](https://apps.apple.com/app/id6799313183) 的设计初衷。

## 常见压缩格式的跨平台现状

虽然 `.zip` 是最通用的格式，但在专业场景下，不同平台倾向于使用更高压缩比的归档格式：
- **7Z (`.7z`)**：采用业界领先的 LZMA 压缩算法，体积比 ZIP 小得多，在开发者和游戏资源分发中极受欢迎；
- **RAR (`.rar`)**：Windows 商业办公与论坛下载资源的事实标准之一；
- **TAR / GZIP / BZIP2 / XZ**：Linux 服务器打包与开源分发的标配；
- **ISO / CAB / VHD / ARJ**：光盘镜像与系统安装归档包。

打开这些文件不应该要求你安装好几个不同的小工具，更不需要去终端敲复杂难记的 `tar -xvf` 命令行。

## 右键原生操作的优雅之处

当你需要解压某个文件时，你的思维与注意力正停留在 **Finder 当前所处的目录中**。你最希望的操作是“随手一点，解压完毕”。

通过深度集成于 macOS 访达右键菜单的 [ZipGo](https://apps.apple.com/app/id6799313183)，你能获得以下丝滑体验：

### 1. “解压到当前”与“解压到同名文件夹”自由选择
右键点击任意压缩包，直接呈现两个极其清晰的选项：
- **解压到当前文件夹**：适合压缩包内部本身就包含顶级父文件夹的规范归档；
- **解压到独立同名文件夹**：彻底杜绝“压缩包炸弹”！即便压缩包里有数百个零散碎文件，ZipGo 也会自动为你新建一个与压缩包同名的文件夹并将所有文件归置其中，保证工作目录整洁有序。

### 2. 覆盖超过 30 种主流与小众格式
支持包括但不限于：`7Z`、`ZIP`、`RAR`、`TAR`、`GZIP`、`BZIP2`、`XZ`、`ISO`、`CAB`、`ARJ`、`LZIP`、`VHD` 等格式。不管是 Linux 安装包还是十年前的旧归档，都能轻松解码解压。

### 3. 原生 Swift 打造，毫秒级多线程响应
ZipGo 针对苹果 Apple Silicon（M1/M2/M3/M4）芯片架构进行了全核多线程并行优化。解压几十 GB 的大型素材包时，性能强劲，不会阻塞系统界面响应。
